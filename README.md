# 名典

输入父母姓、出生年月、性别、名字长度等信息，从**古诗词曲赋、诗经楚辞、古文诸子、成语典故、蒙学经典、中药名、二十四节气、近代经典（毛主席诗词）、古风歌词**中生成有出处、有寓意、好写好听的宝宝名字。支持双胞胎/龙凤胎配对取名。

> 题记：小满胜万全，取名取于诗。

## 快速使用

**双击 `index.html`**，浏览器直接打开即用（纯离线，无网络依赖）。

- 所有数据内置于 `data/` 目录（`.js` 包装的 JSON 字面量），脚本按依赖顺序加载，`file://` 协议下可直接运行——这是刻意不用 `fetch()` 和 ES modules 的原因。
- 若需本地服务器方式打开：`python -m http.server` 后访问 `http://localhost:8000`。
- 网络可用时会自动加载霞鹜文楷字体，不可用时回退系统楷体/宋体，不影响功能。

## 功能

| 输入         | 说明                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 取名模式     | **单名取名** / **配对取名**（双胞胎兄弟、姐妹、龙凤胎）                                                                                                      |
| 父亲姓氏     | 必填。自动识别复姓（欧阳、司马、上官、万俟、单于……共 79 个）；单姓 415 个覆盖《百家姓》全文；未收录的姓氏按单字从字库取拼音笔画兜底                          |
| 母亲姓氏     | 可选。勾选「母姓入名」后解锁：**排列**（父姓在前/母姓在前）× **用字**（单字 → 三字名/双字 → 四字名）四种组合，如「王林月」「王林月华」「林王月」「林王月华」 |
| 性别         | 男 / 女 / 不限（配对模式下改为选择宝宝组合：兄弟/姐妹/龙凤胎）                                                                                               |
| 出生年月     | 可选。仅用于生肖徽章与季节加分（不做八字五行）                                                                                                               |
| 名字长度     | 双字名（3 字全名）/ 单字名（2 字全名）/ 三字名（母姓入名·单字）/ 四字名（母姓入名·双字）；复姓+双字名本身就是四字名                                          |
| 风格偏好     | 诗词曲赋 / 诗经楚辞 / 中药名 / 节气自然 / 不限                                                                                                               |
| 祝福方向     | 平安、聪慧、风雅、健康、爱情、富贵、坚韧、仁善、清朗、自然、事业、福寿                                                                                       |
| 避讳字       | 长辈名讳用字（含常见同音字映射，如避「春」自动避「椿、纯、淳」）                                                                                             |
| **打分权重** | 五维权重滑杆（音律/形美/寓意/性别/字频），实时调整、按比例自动归一、localStorage 记忆，可一键恢复默认                                                        |

**配对取名**：从配对库（91 对）生成成对名字，每对出自同一经典——龙凤胎「金风·玉露」（金风玉露一相逢）、「知·行」（知行合一）、「磐石·蒲苇」（孔雀东南飞）；双胞胎「疏影·暗香」「鲲·鹏」「呦呦·鹿鸣」……每半独立打分过滤（避讳/谐音/风格均生效），按对均分排序。

**随姓方式**（配对模式，填写母姓后可选）：均随父姓 / 均随母姓 / **长随父姓·幼随母姓** / 长随母姓·幼随父姓；龙凤胎额外支持**男随父姓·女随母姓**（如王磐石 · 林蒲苇）与**女随父姓·男随母姓**。母姓半侧的妙配检测自动生效（母姓白 → 白玉露命中「白+玉」双关）。

每个候选名字卡片展示：出处（原句+作者+朝代）、寓意、拼音、**音律点评、书写点评**、五维评分（音律/形美/寓意/性别/字频），支持收藏（localStorage）、复制、按维度重排序，以及**「换一批」循环翻页**（单名模式一次最多 90 个、配对模式最多 60 对，按每批数量分页）。

## 打分设计

候选 = 策展词库（974 词条，每个自带出处） × 姓氏，硬过滤后五维打分：

- **音律 30%**：平仄交替、黄金调型（如「王子衿 231」）、声母韵母连读拗口度、三连平/仄罚分、叠字豁免、谐音三层检测（字面/拼音串/危险字）
- **形美 25%**：笔画总数与梯度、结构搭配（左右/上下相间）、行书连笔友好度（首末笔、连笔打分）
- **寓意 35%**（最高权重）：出处权重（千古名句>名篇>雅词）、祝福方向匹配、**「姓+名」妙配表**（金风玉露式双关：叶知秋、白玉露、杜若、苏堤、徐长卿……共 73 组）
- **性别 5%**、**字频 5%**（防重名、避生僻）

排序后还有**多样性过滤**：整批候选内同一首字最多 3 个（避免「清 ×」「× 月」扎堆），其余按原序递补。五维权重可通过界面滑杆实时调整（按比例自动归一）。

硬过滤（不进打分直接剔除）：避讳字（含同音映射）、性别冲突、不雅谐音（吴礼/杜子腾/沈京冰等）、生僻字（字频排名 >20000）。

## 目录结构

```text
├── index.html            # 单页入口（双击即用）
├── css/style.css         # 中式美学：宣纸底/墨字/朱砂红
├── js/
│   ├── phonetics.js      # 音律：声调组合、声韵连读、谐音检测
│   ├── calligraphy.js    # 形美：笔画搭配、结构搭配、连笔性
│   ├── meaning.js        # 寓意：出处权重、祝福匹配、姓氏双关
│   ├── scoring.js        # 五维合成（权重在 data/config.js）
│   ├── candidate.js      # pipeline：生成→过滤→打分→排序→去重→多样性→分批
│   ├── pairs.js          # 双胞胎/龙凤胎配对生成（随姓方式/对均分）
│   └── ui/               # form / results / detail 交互模块
├── data/
│   ├── names.js          # 词条主库（974 条：诗经/楚辞/唐诗/宋词/汉魏/元曲/中药/节气/雅词/近代/单字）
│   ├── pairs.js          # 双胞胎/龙凤胎配对名库（91 对，出自同一经典）
│   ├── chars.js          # 字级属性库（1132 字：拼音/声调/笔画/结构/连笔/字频）
│   ├── surnames.js       # 415 单姓 + 79 复姓（百家姓全文 0 缺失，未收录按字兜底）
│   ├── bad_homophones.js # 谐音黑名单（字面/拼音/危险字三层）
│   └── config.js         # 权重、黄金调型、73 组妙配表、避讳映射、点评模板
├── tools/
│   ├── validate.js       # 数据完整性校验（node tools/validate.js）
│   └── audit.js          # 内容质量审计（node tools/audit.js）
└── test/                 # 规则断言（node test/run.js 或双击 test/test.html）
```

## 词库编写规范（扩展词库时遵守）

1. **一字一验**：词条每个字必须存在于 `chars.js`，缺失即 `validate.js` error
2. **出处可溯源**：`source.text` 必须是真实原文；无法确证标 `verified:false`（校验会警告，需人工校对）；字面可能引歧义的词条直接放弃
3. **双关优先**：与常见姓构成妙配的词条（苏合、叶知秋、白芷……）同步录入 `config.surnameCompat`
4. 名字质量 = 词库质量：宁缺毋滥

## 开发与验证

```bash
node tools/validate.js   # 数据完整性校验（外键/拼音/声调/枚举/配对引用）
node tools/audit.js      # 内容质量审计（出处含名字用字/作者朝代一致/危险字/标签枚举）
node test/run.js         # 41 条规则断言（坑娃名过滤/叠字豁免/避讳/四字名/配对/黄金调型/边界…）
```

调参：所有权重、黄金调型、罚分集中在 `data/config.js`，改数字即可，不碰代码。
